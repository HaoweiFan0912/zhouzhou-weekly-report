# 复古手撕拼贴插图 prompt 示例

这是一篇真实新闻的完整设计和 prompt，用来演示 SKILL.md 第 3 步怎么落地。新文章照这个结构写，事实一律以原文为准。

原文：Artemis，'PERILS finalises industry loss estimate for Australia east coast SCS at AU $1.62bn'

## 核对信息（写在 prompt 文件开头）

**核心信息**：PERILS 公布 2025 年 10 月底澳洲东海岸强对流风暴的最终行业损失，为 16.2 亿澳元。

**贴图与原文事实对照**：

| 贴图 | 对应的原文事实 |
|---|---|
| 澳洲东海岸旧地图剪片，昆士兰用红笔圈出 | 波及昆士兰、新南威尔士、维多利亚三州；昆士兰占总损失 94% |
| 撕下的日历页，「10.26–11.1」 | 风暴发生在 2025 年 10 月 26 日至 11 月 1 日 |
| 手写纸条：「11.08 → 15.12 → 15.01 →」，末尾箭头指向画面里的大数字 | 前三次损失估计（单位亿澳元）；最终值已经是关键数字，不再重复写 |
| 布里斯班城市照片剪片 | 10 月 26 日布里斯班地区受灾最重 |
| 龙卷风黑白新闻照片剪片 | 同日墨尔本西郊遭遇强龙卷风 |
| 屋顶太阳能板照片碎片 | PERILS 认为屋顶光伏等易损资产增多推高了损失 |

**图上全部可读文字**（每条只出现一次）：「澳洲风暴最终定损」「16.2亿澳元」「昆士兰 94%」「10.26–11.1」「11.08 → 15.12 → 15.01 →」

## 编译后的 prompt

```
创作一张 16:9 的复古手撕拼贴编辑海报，用作微信公众号文章的正文配图。中文。

【主题】澳大利亚东海岸强对流风暴的最终行业损失定格在 16.2 亿澳元。

【第一层：直接展现核心信息，占画面 50–60%】
- 主标题：画面左侧，约占宽度 40%，一行黑色粗体中文「澳洲风暴最终定损」，印在一大块边缘撕裂的米白纸上，像旧报纸头版的剪切标题。字体醒目，与底色反差强，被其他纸片遮挡的部分不超过一成。
- 关键数字：「16.2亿澳元」用一组更大的剪报拼字单独做出来，朱红底黑字，压在标题纸的右下方并略微倾斜，是全图最醒目的数字。这串数字在图上只出现这一次。
- 主视觉：画面右侧中央，一张大幅黑白新闻照片剪片：被强风掀开的郊区住宅屋顶、散落的瓦片，边缘撕裂，四角用半透明黄色胶带固定，是全图最完整、最清晰的图像。

【第二层：用贴图间接交代背景，分布在四周和主视觉背后】
- 主视觉左下方压着一块澳洲东海岸的旧地图剪片，昆士兰被红色圆珠笔粗略圈出，旁边一张小纸签手写「昆士兰 94%」。
- 右上角一张撕下的旧日历页，印着「10.26–11.1」。
- 底部中间一张横向的手写纸条，用钢笔写着「11.08 → 15.12 → 15.01 →」，表示前三次估损，最后的箭头指向上方的大数字，纸条一端被胶带粘住。
- 主视觉背后露出一角布里斯班河岸城市的老照片，以及一角龙卷风漏斗云的黑白新闻照片，都只露出一部分。
- 右下角一小块屋顶太阳能板的照片碎片。
- 空隙处铺旧报纸版面作底纹，报纸上的正文只是看不清的印刷纹理。

【排版】只有一个视觉焦点：主标题和「16.2亿澳元」→ 被掀开的屋顶，形成从左上到右侧的 Z 字形阅读路线。四边留约 5% 安全边距，标题和数字不贴边。画面饱满，层次分明，不是素材乱堆。

【配色】旧报纸米黄、黑色油墨、牛皮纸棕做底，朱红作为唯一强调色，只用在关键数字和红笔圈注上。

【质感】真实纸张纤维、撕裂毛边、折痕、胶带的半透明反光、纸片之间的投影、半调网点、复印颗粒、轻微的油墨错位。

【禁止】同一条文字或数字出现两次（「16.2亿澳元」只能出现一次）；可读的假新闻句子；真实公司 logo；除上述文字以外的任何可读文字；和上述不一致的数字；干净的矢量风格；多个抢眼的焦点；素材无序堆叠。
```
